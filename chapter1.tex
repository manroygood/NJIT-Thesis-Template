\chapter{Document Structure}
\label{ch:structure}

A \LaTeX\ dissertation project is structured like a well-organized software codebase: split into modular functional units contained in separate files. This chapter explains the overall structure required by the New Jersey Institute of Technology Office of Graduate Studies (GSO), how each file in this template contributes to the final document, and how to compile the project locally and on Overleaf.

\section*{The Parts of a Dissertation, in Order}

An NJIT dissertation consists of three primary divisions: the preliminary front matter, the main body (chapters and appendices), and the back matter (references). These components appear in the following strict order:

\begin{description}
\emergencystretch=2em
\item[Abstract] A concise summary of the research questions, methodology, and conclusions. By NJIT guidelines, this page is unnumbered and precedes the title page. Defined in \texttt{abstract.tex} and generated by \verb+\makeabstract+.

\item[Title Page] The formal title page declaring degree, department, joint institution (if applicable), and defense date. This page is considered Roman numeral~i, but no number is displayed on the page. Generated automatically by \verb+\maketitle+ using metadata in \texttt{biography.tex}.

\item[Copyright Page] Declares the copyright holder and defense year. Unnumbered. Generated automatically by \verb+\makecopyright+.

\item[Approval Page] Contains the signature lines for the dissertation advisor and committee members with their official academic titles as listed in the graduate catalog. Unnumbered. Configured in \texttt{approval.tex} and generated by \verb+\makeapproval+.

\item[Biographical Sketch] Displays academic background, degrees earned (in reverse chronological order), major field of study, and a listing of presentations and publications. Roman page numbering begins visibly here (typically on page~iv). Configured in \texttt{biography.tex} and generated by \verb+\makebiography+. The publication list is generated automatically via \BibTeX\ / \texttt{biblatex} using the keyword \texttt{me}.

\item[Dedication] (Optional) A brief personal dedication. Centered and formatted with single spacing. Configured in \texttt{dedication.tex} and generated by \verb+\makededication+.

\item[Acknowledgment] Formal recognition of academic guidance, committee assistance, grant funding and financial support, technical and administrative assistance, and personal gratitude. Configured in \texttt{acknowledgment.tex} and generated by \verb+\makeacknowledgment+.

\item[Table of Contents] Lists all chapters, sections, subsections, appendices, and post-TOC preliminary lists with leader dots connecting titles to page numbers. Generated automatically by \verb+\tableofcontents+.

\item[List of Tables] Generated automatically by \verb+\listoftables+. If your dissertation contains no tables, comment out this command in \texttt{main.tex}.

\item[List of Figures] Generated automatically by \verb+\listoffigures+. If your dissertation contains no figures, comment out this command in \texttt{main.tex}.

\item[List of Symbols] (Optional) Defines mathematical symbols and physical constants used throughout the text. Configured in \texttt{listofsymbols.tex} and generated by \verb+\makelistofsymbols+.

\item[Glossary of Terms] (Optional) An alphabetical list of definitions. Configured in \texttt{listofdefinitions.tex} and generated via \verb+\makeglossaryofterms+.

\item[Preface] (Optional) Introductory remarks appearing immediately before Chapter~1. Enclosed within the \texttt{preface} environment in \texttt{preface.tex}.

\item[Main Body] The dissertation chapters, beginning with Arabic page number~1 at \verb+\startbody+. Each chapter is housed in its own file (e.g., \texttt{chapter1.tex}, \texttt{chapter2.tex}).

\item[Appendices] Supplementary mathematical proofs, data tables, or algorithm listings. NJIT enforces a strict rule: if there is only a \textbf{single appendix}, it must be labeled \textbf{APPENDIX} (without a letter like "A"). If there are \textbf{multiple appendices}, they must be numbered \textbf{APPENDIX A}, \textbf{APPENDIX B}, etc. This template fully automates both cases.

\item[References] The bibliography, styled consistently and sorted according to the field's standard conventions. Generated from \texttt{references.bib} via \texttt{biblatex} and \texttt{biber}.
\end{description}

\section*{The Template Files}

Here is a breakdown of the files included in this template and how each should be edited:

\begin{description}
\emergencystretch=2.5em
  \item[\texttt{dmsthesis.cls}] The \LaTeX\ class file. It encapsulates all official NJIT Graduate Studies Office formatting rules, including 1.5-inch left margins for binding, 1.0-inch top/bottom/right margins, double line spacing for body text, centered bold uppercase chapter titles, multi-page continuation headers for the Table of Contents, Lists of Figures and Tables, and correct appendix handling. You should not need to edit this class file directly.

  \item[\texttt{main.tex}] The master control document. It loads the class, includes packages and macros, sets the graphicspath, loads the front matter, and arranges the chapters and appendices via \verb+\input+ statements.

  \item[\texttt{packages.tex}] Loads optional \LaTeX\ packages (such as \texttt{tabularx}, \texttt{amsmath}, \texttt{amssymb}, \texttt{amsthm}, \texttt{graphicx}, \texttt{subcaption}, \texttt{booktabs}, \texttt{xurl}, and \texttt{biblatex}). Add any additional packages needed for your research here.

  \item[\texttt{macros.tex}] Defines custom mathematical shortcuts and theorem environments (e.g., Theorem, Lemma, Definition, Proposition, Corollary).

  \item[\texttt{abstract.tex}] Enter the text of your abstract here. The class file automatically supplies the centered title and author header.

  \item[\texttt{approval.tex}] Defines the dissertation advisor and committee members using the \verb+\advisor+ and \verb+\member+ commands. Faculty titles must match the catalog.

  \item[\texttt{biography.tex}] Contains your dissertation title, author name, major, degree title, department, institution, defense date, and degrees earned (entered with the \verb+\degree+ command). Also includes the hook for \verb+\printmypublications+.

  \item[\texttt{dedication.tex}] Contains your optional dedication. If you do not wish to include a dedication, simply comment out \verb+\dedication{\input{dedication}}+ in \texttt{main.tex}.

  \item[\texttt{acknowledgment.tex}] Contains your acknowledgments. Follow the recommended ordering: advisor first, followed by committee, financial sponsors, technical support, and family/friends.

  \item[\texttt{listofsymbols.tex}] Contains definitions of notation and symbols. Included via \verb+\symbols+ in \texttt{main.tex}.

  \item[\texttt{listofdefinitions.tex}] Contains glossary terms. Included via \verb+\glossaryofterms+ in \texttt{main.tex}.

  \item[\texttt{preface.tex}] An optional preface. If not needed, comment out \verb+\input{preface}+ in \texttt{main.tex}.

  \item[\texttt{chapter1.tex}, \texttt{chapter2.tex}, \ldots] The individual chapter files. Keeping chapters in separate files allows you to comment out finished chapters while drafting new ones to speed up compilation.

  \item[\texttt{appendix.tex}] For a single appendix, edited using the \verb+\oneappendix+ command. If multiple appendices are desired, use \texttt{appendixA.tex} and \texttt{appendixB.tex} (with \verb+\chapter+).

  \item[\texttt{references.bib}] A standard \BibTeX\ database of citations. Any entry with the field \verb+keywords = {me}+ will also be included automatically in the Presentations and Publications section of your Biographical Sketch.

  \item[\texttt{Graphics/}] Directory containing all figures, plots, and diagrams.
\end{description}

\section*{Compiling the Dissertation}

\subsection*{Recommended: \texttt{latexmk}}
The easiest and most reliable way to compile your dissertation locally is with \texttt{latexmk}:
\begin{verbatim}
latexmk -pdf main.tex
\end{verbatim}
\texttt{latexmk} monitors all file dependencies, automatically invokes \texttt{biber} for the bibliography and publications list, and runs \texttt{pdflatex} as many times as necessary to ensure all cross-references, Table of Contents entries, and list page numbers are completely up to date.

\subsection*{Manual Compilation Steps}
If running commands manually in a terminal:
\begin{enumerate}
  \item \verb+pdflatex main.tex+ (generates auxiliary files and bibliography requests)
  \item \verb+biber main+ (processes \texttt{references.bib} and resolves citations)
  \item \verb+pdflatex main.tex+ (incorporates bibliography and generates cross-references)
  \item \verb+pdflatex main.tex+ (resolves final page numbers for TOC and lists)
\end{enumerate}

\subsection*{Working on Overleaf}
The template works out of the box on Overleaf. Ensure that the project compiler is set to **pdfLaTeX** and that the bibliography engine is set to **Biber** in the Overleaf project settings.

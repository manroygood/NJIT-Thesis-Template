\chapter{Packages loaded by the template}
\label{app:packages}

Further information on each package, including its full documentation, is available at \url{https://ctan.org}, the Comprehensive \TeX\ Archive Network: search for the package by name. If compiling stops because a package is missing, see Subsection~\ref{subsec:missingpackages}.

This appendix lists every package loaded in \texttt{packages.tex}, in the order it is loaded, with the options the template chooses and why. Add packages your research needs at the end of that file. Packages that the template needs for its layout are loaded by the class file itself and are listed in Section~\ref{sec:classpackages}; you should not need to load those again.

\section{Packages in \texttt{packages.tex}}

\begin{description}
\item[\texttt{fontenc}] Loaded with the option \texttt{T1}, which selects modern 8-bit font encoding. Accented letters then hyphenate correctly, and characters such as < and > print correctly in text.

\item[\texttt{tabularx}] Provides the \texttt{tabularx} environment, whose \texttt{X} columns stretch to fill a given width. The sample tables use it to make tables exactly as wide as the text.

\item[\texttt{booktabs}] Provides the horizontal rules \verb+\toprule+, \verb+\midrule+, and \verb+\bottomrule+, which give tables with better spacing than \verb+\hline+.

\item[\texttt{array}] Extends column specifications, for example \verb+>{\raggedright}p{2in}+ to set the alignment inside a paragraph column. The class also loads it.

\item[\texttt{amsmath}] The standard package for displayed mathematics: \texttt{align}, \texttt{gather}, \verb+\eqref+, \verb+\text+, and more. No options are needed.

\item[\texttt{amsthm}] Provides \verb+\newtheorem+ styles and the \texttt{proof} environment. The theorem environments themselves are defined in \texttt{macros.tex}.

\item[\texttt{mathtools}] Extends \texttt{amsmath} with fixes and additions such as \verb+\coloneqq+ and paired delimiters.

\item[\texttt{newtxtext}] Sets the text in a Times clone (TeX Gyre Termes). The GSO requires Times New Roman or Arial at 12~pt.

\item[\texttt{newtxmath}] Sets mathematics in fonts that match the Times text, and provides the AMS symbol fonts, so \texttt{amssymb} and \texttt{amsfonts} must \emph{not} be loaded as well. It must be loaded after \texttt{amsmath}.

\item[\texttt{graphicx}] Provides \verb+\includegraphics+. Images are found in the \texttt{Graphics/} folder because \texttt{main.tex} sets \verb+\graphicspath{{Graphics/}}+.

\item[\texttt{xcolor}] Defines colors by name. The template uses it only to color source-code listings.

\item[\texttt{subcaption}] Provides the \texttt{subfigure} environment for figures with labelled parts (a), (b), and so on, as in Figure~\ref{fig:letters}. It works with the caption settings in the class.

\item[\texttt{xurl}] Allows long URLs to break at any character, so URLs in tables and in the bibliography do not run into the margin.

\item[\texttt{csquotes}] Handles quotation marks. The command \verb+\MakeOuterQuote+ that follows it lets you type a straight double quote and get correct opening and closing quotation marks. It also makes that character special, so it can clash with some packages, such as \texttt{babel} shorthands for German.

\item[\texttt{listings}] Typesets source code, as in Section~\ref{sec:source_code}. The \verb+\lstset+ commands that follow it choose a small typewriter font, no line numbers, MATLAB as the default language, line breaking for long lines, blue keywords, red emphasis for a few control words, and cyan comments. Change \texttt{language} to match your own code.

\item[\texttt{biblatex}] Formats citations and the bibliography, with \texttt{biber} as the back end. It is loaded through the \verb+\loadbiblatex+ command so that the style can be set once, with \verb+\mycitestyle+, from the table of styles in \texttt{packages.tex} (see Section~\ref{sec:bibliography}). The other options are:
  \texttt{backend=biber}, the program that processes \texttt{references.bib};
  \texttt{doi=false}, \texttt{url=false}, and \texttt{isbn=false}, which leave DOIs, URLs, and ISBNs out of the reference list;
  \texttt{giveninits=true}, which shortens given names to initials;
  \texttt{sortcites=true}, which sorts the numbers in a multiple citation, giving [1, 4, 5] rather than [5, 1, 4];
  and \texttt{defernums=true}, which assigns a number to an entry only when it is cited or printed, so entries in \texttt{references.bib} that are never used do not leave gaps in the numbering.
  The \verb+\defbibheading+ command after it gives the publications list in the Biographical Sketch an empty heading, because the class prints its own.
\end{description}

\section{Packages Loaded by the Class File}
\label{sec:classpackages}

The class file \texttt{njit\_thesis.cls} loads these packages itself, because the NJIT layout depends on them:
\begin{itemize}
\item \texttt{geometry}, for the 1.5-inch left margin and 1-inch top, bottom, and right margins;
\item \texttt{setspace}, for double spacing of the text and single spacing of headings, captions, lists, and references;
\item \texttt{pdflscape}, for landscape pages;
\item \texttt{caption}, for the caption layout (bold label, two spaces, no colon; table titles above, figure captions below);
\item \texttt{etoolbox}, for the hooks the class uses internally;
\item \texttt{array} and \texttt{longtable}, for the two-column List of Symbols and Glossary of Terms.
\end{itemize}
